# Clear Region Outliner

一个完全在浏览器本地运行的图像纯色块化与边界描线工具。它把 PNG / JPEG / WebP 转换为离散、内部 RGB 完全一致的色块，并根据最终标签图统一描线。

## 启动

无需安装第三方依赖，只需要 Node.js 18+：

```bash
git clone https://github.com/HerculeLiu/Inkline.git
cd Inkline
npm start
```

打开 <http://127.0.0.1:4173>。图片读取、自动分析、分割、描线和 PNG 编码都在当前浏览器完成；页面没有任何网络请求，也没有服务端上传。

> 不要直接双击 `index.html`。模块化 Web Worker 需要通过本地 HTTP 服务加载。

## 使用

1. 拖入 PNG、JPEG 或 WebP，或先选择一个内置样图。
2. 自动模式会先读取实际相邻色差分布，并把估计值显示在参数框中。
3. “分割方法”默认使用原有稳定管线；可切换到 `FH + RAG（实验）` 或 `多尺度融合（实验）` 比较细节保留效果。
4. 点击“开始处理”。处理中可继续操作页面，算法运行在 Web Worker。
5. 在“原图 / 纯色化 / 边界图 / 最终结果”之间切换；对比模式可以拖动中线。
6. 如果关闭自动模式，当前估计值会保留并变为可编辑。参数改变后必须重新处理，旧结果不会被悄悄覆盖。
7. 点击“下载 PNG”导出与输入完全相同的像素尺寸。

## 参数与单位

- 局部色差：相邻像素边的 OKLab 欧氏距离，界面显示值为原始距离 × 100。
- 全局色差：合并后区域 OKLab 三通道边界盒上界，同样使用 `ΔOK × 100`；不得小于局部阈值。
- 最小色块：原始分辨率下的像素数。
- 剩余面积：用最终同款栅格线宽模拟描线后，区域应剩余的面积比例。低于此值只会成为清理候选，不会被无条件删除。
- 描边宽度：1–8 个原图像素；导出时不做抗锯齿混色。
- 预处理平滑：0–5 次轻度保边平均，只影响分割判断；最终代表色仍来自原图。
- 邻接方式：4 或 8 邻接。边界图仍按像素栅格的水平/垂直共享边提取。

## 算法约束

1. 所有 `alpha > 0` 像素先转换到 OKLab；`alpha = 0` 不参与统计或区域扩张。
2. 相邻边按量化到 `1 / 32768` OKLab 的桶稳定排序。同桶内保持固定扫描顺序，因此结果可复现。
3. 区域合并必须同时满足局部边阈值与合并后 OKLab 边界盒跨度上界，避免渐变发生链式漂移。
4. 小区域按面积与模拟描线后的剩余比例进入候选，只有存在满足全局跨度约束的相邻区域时才会合并。
5. 最终区域代表色使用原图逐通道算术均值并取整。它不是艺术语义判断，但区域内每个像素都会写入同一个精确 RGB 三元组。
6. 边界只从最终 `labelMap` 提取。共享边扫描一次，两个代表 RGB 恰好相同的不同区域也会保留边界。
7. 导出前逐区域检查非边界颜色一致、边界精确线色、透明像素无 alpha 泄漏。

## FH + RAG 实验方法

实验方法放在独立模块 `src/prototype-fh-rag.js`，不会替换现有方法。它使用 Felzenszwalb–Huttenlocher 风格的自适应图分割建立初始区域，随后恢复被 FH 过度切开的弱共享边界，再以区域邻接图（RAG）评估边界强度、合并后的重建损失和颜色跨度。封闭且边界证据明确的内孔会被显式保护，有明显共享边界的小高光也不会仅因面积小而被吞掉；低对比噪声不会因为“封闭”就自动获得保护。

当前实验只验证“分区 + 清理”这一核心假设；曲线拟合与矢量化尚未接入。界面和结果统计会一直标记 `EXPERIMENTAL`，便于与稳定结果并排判断。

## 多尺度融合实验方法

该方法使用当前全局色差生成干净并完成碎块清理的粗层，同时自动派生一个较低全局色差、但不执行碎块清理的细节候选层。最终颜色以粗层为底，只将封闭、面积有限且相对粗层颜色偏差明确的细区域提升回来；描边则独立生成，只补回共享边界色差足够明确的细层边界。这样字母内孔、图标和高光可以恢复，而低对比色块不会因为获得独立标签就一律描成黑线。实验实现位于 `src/prototype-hierarchical-fusion.js`；它不会修改稳定方法或 FH + RAG 的行为。

## 测试与可再现样图

```bash
npm test
npm run fixtures
```

测试覆盖：OKLab 参考值、双矩形共享边界、渐变链式漂移、空间断开的同色区域、同色不同标签边界、透明图、自动噪声估计、稳定性、不合法参数，以及高阈值下的头发高光与 O 形封闭内孔保护。

`npm run fixtures` 会在 `fixtures/generated/` 生成三组可再现 PNG，每组包含原图、纯色图与最终描线图：

- 两块带轻微噪声的接触色块；
- 相邻变化很小但整体跨度很大的线性渐变；
- 带半透明前景与完全透明背景的色块岛。

## 浏览器与资源边界

- 建议使用最新版 Chrome、Edge、Firefox 或 Safari。
- 单边上限为 4096 像素；为保护浏览器内存，总像素超过 4,194,304 时会明确拒绝处理，不会静默缩放。
- 1024 × 1024 是推荐工作尺寸。8 邻接比 4 邻接需要更多邻接边内存。
- 更换图片或重新处理会终止旧 Worker，过期任务 ID 的消息不会更新界面。

## 已知限制

- 这是颜色统计与空间邻接工具，不理解头发、云朵、眼睛等语义，也不能恢复艺术家的主观分区。
- 强渐变会被全局跨度规则切成若干确定但未必审美最优的条带。
- OKLab 边界盒是实际最大两两色差的保守上界，可能拒绝本可接受的区域合并。
- 代表色当前采用均值而不是逐通道中位数，以保持百万像素图的内存可控。
- 细长高光和小眼睛可能因线宽而成为清理候选；无法安全合并时会保留，并在统计中提示。
- 二值透明策略会把 `alpha > 0` 的前景硬化为 255，柔边输入的边缘会变硬。
